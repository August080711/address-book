# 通讯录管理系统

C 语言练习项目（大一）：一个简单的命令行通讯录，支持添加联系人并查看全部联系人。

## 功能

- [x] 第一步：菜单 + 添加联系人 + 显示全部（内存版）
- [ ] 第二步：查找、删除、修改联系人
- [ ] 第三步：退出时保存到文件，下次启动时读回

联系人信息：姓名、电话、年龄，最多保存 100 人。

## 如何运行

```bash
gcc address_book.c -o address_book
./address_book
```

也可以用 Dev-C++ 打开 `address_book.c`，按 F11 编译运行。

## 操作

```
--- 通讯录 ---
1. 添加  2. 显示全部  0. 退出
```
